# DFI JS/REACT Quiz - JavaScript & React 19 Exam & Assessment Portal ⚡⚛️

> **State-of-the-Art Examination & Practice Portal for JavaScript (ES6+) and React 19**

DFI JS/REACT Quiz is a comprehensive developer evaluation platform designed to test, assess, and reinforce deep knowledge across modern JavaScript and React 19 through 400 authentic, verified multiple-choice questions with code snippets, detailed explanations, and pro tips.

---

## 🌟 Key Features

- 🏆 **Certification Exam Mode**: Configurable question count (20, 50, 100, 200 Qs) with strict countdown timer, question palette navigation, and instant certification scoring.
- 💡 **Topic Mastery & Practice Mode**: Filter and practice by specific curriculum modules (e.g., Closures, Event Loop, React 19 Actions, Custom Hooks) with immediate explanations.
- ⚡ **10-Q Speed Sprint**: Rapid-fire randomized drill for quick daily practice.
- 🔄 **Weakness / Mistake Vault**: Automatically tracks missed questions for targeted remediation until 100% mastery.
- 🔖 **Bookmarks Bank**: Save challenging questions to revisit anytime.
- 🗺️ **Interactive Syllabus & Curriculum Explorer**: Browse all 28 JavaScript sections and 16 React 19 modules.
- 📊 **Performance Analytics**: Real-time topic mastery breakdown bars, exam history, accuracy percentage, and test streaks.
- 🎵 **Web Audio Sound Effects**: Zero-dependency synthetic audio cues with one-click mute/unmute.
- 🎨 **Midnight Sapphire UI**: Built with modern glassmorphism, responsive layout, and dark mode aesthetics.

---

## 📚 Question Banks (400 Total Questions)

1. **JavaScript Bank (200 Questions)**:
   - Coding Principles (DRY, KISS, SRP, Pure Functions)
   - Scope, Hoisting & Temporal Dead Zone
   - Closures & Encapsulation
   - Event Loop, Concurrency & Asynchronous JS (Promises, Async/Await)
   - DOM Manipulation, Browser APIs & Web APIs
   - Modern ES6+ Features & OOP

2. **React 19 Bank (200 Questions)**:
   - Declarative UI & Virtual DOM
   - Component Lifecycle, Props & State
   - Core Hooks (`useState`, `useEffect`, `useRef`, `useContext`)
   - **React 19 Innovations**: Actions, `useActionState`, `useFormStatus`, `useOptimistic`, `use()` API, Server Components, and Asset Loading
   - Controlled Forms, Performance Basics & Routing

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn`

### Installation & Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
